# Sloosh V1 · The Weekly

Static prototype of the The Weekly homepage direction. No build step.

- Run locally: `npx serve .` (or `python3 -m http.server`), then open http://localhost:3000
- Deploy: Vercel, framework preset **Other**, no build command, output directory `.`

Files: `index.html` (the page), `kit.css` / `kit.js` (shared theme, sounds, motion), `support.js` (page runtime), `media/` (images and videos).
